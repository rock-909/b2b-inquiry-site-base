# 技术栈

本文档解释当前采用的技术及职责；精确版本以 package.json、lockfile、Next 配置和部署配置为准。

## 运行与构建

- Next.js：页面、路由、metadata 和服务端渲染；
- React：组件和交互；
- TypeScript：类型边界；
- pnpm：依赖和脚本入口；
- OpenNext + Cloudflare Workers：生产构建和运行；
- Wrangler：Cloudflare dry-run、部署和平台语义验证。

pnpm build 与 pnpm website:build:cf 写入同一个 .next，不能并行运行。Playwright webServer 也可能重建 .next；Lighthouse 使用独立的 .next-lighthouse。

当前 TypeScript 统一使用 6.0.2：项目类型检查、Next.js JavaScript compiler API、
ESLint 及其他工具共享同一个 CLI 与 compiler API 基线。TypeScript 7 只作为独立实验
观察，不进入主线；重新评估条件和回滚步骤见 `TypeScript 7双轨迁移.md`。

Cloudflare 基线当前使用固定 commit 的 OpenNext Cache Components 适配器、R2
incremental cache，以及把 `src/proxy.ts` 打成 workerd 单文件的本地补丁。上游监控、
正式版本迁移和回滚步骤见 `OpenNext Draft适配器.md`。

## 内容与国际化

- src/content/pages/en/*.ts：页面正文和页面级 SEO 输入，直接进入 Next/OpenNext 模块图；
- `messages/base/{locale}/messages.json`：UI 文案；
- src/config/pages.config.ts：静态页面注册；
- locale 配置、messages 和静态页面模块必须一起维护；
- 当前公开站点 English-only，但 i18n 管道保留。

## UI 与主题

- Base UI：负责 Dialog、Popover、Select、Combobox 等复杂交互 primitive；
- `src/components/ui/*`：项目正式 UI 入口，业务代码不直接依赖 Base UI；
- 原生 HTML：普通按钮、输入框和 textarea 等浏览器已有可靠语义的控件；
- Tailwind CSS + `src/app/theme.css`：页面样式和网站整体换肤。

精确 Base UI 版本以 `package.json` 和 lockfile 为准，不在本文维护版本号。

## 询盘与安全

询盘链路由统一表单、服务端验证、Turnstile、下游 provider 和 owner receipt 组成。Resend 是 owner 日常处理询盘的主通道，Airtable 是结构化备份；先发邮件，再把邮件结果写入 Airtable Message。任一渠道成功即接受，两者都失败才让买家重试。

敏感配置来自环境变量和平台 secrets，不写入文档或测试 fixture。

## 测试和质量

- Vitest：单元、集成和架构行为；
- Playwright：浏览器和部署 smoke；
- ESLint、type-check、content/i18n checks：提交和 CI 基础门禁；
- architecture/dependency/Cloudflare checks：保护结构、生成物和平台语义。

## 版本真相

文档不维护完整版本表。要判断版本、脚本或平台配置，读取 package.json、pnpm-lock.yaml、next.config.ts、open-next.config.ts、wrangler.jsonc 和当前测试结果。
