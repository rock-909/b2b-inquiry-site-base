# 项目

这是面向 OEM / 批发客户的 B2B 询盘站模板，默认包含基础产品目录、统一询盘链路和英语/西班牙语多语言示例。

模板核心负责稳定的询盘、安全、SEO、内容和 Cloudflare 交付能力。当前模板默认提供 Products 列表和详情页；派生站可以保留、扩展，或在完成依赖清理和门禁验证后移除。不要为不同业务预先增加运行时 mode。

## 当前目标

- 介绍当前业务能提供的 offering 和合作范围；
- 帮助买家整理项目背景和报价需求；
- 通过唯一的询盘表单承接买家询盘；
- 在 Cloudflare 上稳定部署 OpenNext 站点。

## 当前公开范围

- 英语是默认公开语言，西班牙语作为第二语言示例；
- 默认英语路径不带 locale 前缀，西班牙语路径使用 `/es/` 前缀；
- 当前公开页面是 Home、Products、About、Contact、Privacy、Terms；
- 业务范围以 owner 确认后的 offering 和内容配置为准。
- 产品目录是当前模板的默认公开能力；派生站按真实业务替换或扩展 offering 内容，并复用同一询盘链路。

## 非目标

这不是通用 starter、博客系统或多站点 profile 平台。旧 starter 资料、旧 locale 路由、旧产品命名和历史计划不能覆盖当前运行事实。

## 主要用户旅程

了解业务范围 -> 查看公司与合作说明 -> 提交联系或报价询盘 -> 由真实服务和 owner 处理后续。

当前业务事实以代码和内容入口为准：offering 配置、静态页面模块、基础消息文件和站点配置优先于旧文档。

## 内容与品牌入口

- 品牌事实：src/config/single-site.ts；
- SEO 与 crawl：src/config/single-site-seo.ts；
- 页面正文：src/content/pages/{locale}/*.ts；
- UI 文案：messages/base/{locale}/messages.json；
- 业务事实：offering 配置和内容入口。

不要把长正文塞进 messages，也不要在页面组件里硬编码用户可见文案。title / description 是页面内容输入，seo.title / seo.description 是 metadata 输入；updatedAt 表示买家可见内容变更，lastReviewed 表示人工复核时间。

文案必须准确表达业务范围、交付和询盘承诺。旧 starter 文案、占位 profile、未经 owner 确认的供应商或性能声明不能进入公开内容。新增语言必须同步 locale 配置、messages、静态页面模块、SEO 和路由测试，不能只复制页面文件。

## 公开行为和平台边界

- 默认语言 canonical URL 不带 locale 前缀，非默认语言 canonical URL 带对应 locale 前缀；非法和不存在路径必须按路由契约返回正确状态。
- 页面正文在 `#main-content` 中服务端渲染一次；主要内容不依赖 JavaScript 才能阅读。
- 优先使用 Server Components；只有真实浏览器状态或交互需要时才进入 Client。
- 询盘链路是公开表单 -> schema / Turnstile -> 产品上下文确认 -> provider receipt -> Owner 通知。重复询盘可以接受，丢失询盘不接受。
- OpenNext 构建、Wrangler dry-run、预览 smoke、CI 绿灯和 HTTP 200 不能单独证明正式上线或真实 provider 成功。

真相优先级：运行态和实际服务 > 捕获流量 > 当前配置和测试 > 本文档 > 历史 spec、计划和审查记录。
