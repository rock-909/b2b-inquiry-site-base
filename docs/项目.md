# 项目

这是面向 OEM / 批发客户的英文 B2B 询盘站模板。

模板核心负责稳定的询盘、安全、SEO、内容和 Cloudflare 交付能力。派生站通常会增加产品目录、服务目录或混合 offering 页面；这些页面和数据属于业务内容层，不要求模板核心内置固定目录 schema 或运行时模式。

## 当前目标

- 介绍当前业务能提供的 offering 和合作范围；
- 帮助买家整理项目背景和报价需求；
- 承接 Request Quote / Contact 询盘；
- 在 Cloudflare 上稳定部署 OpenNext 站点。

## 当前公开范围

- 只有英文公开站点；
- 公开路径不带 locale 前缀；
- 当前公开页面是 Home、About、Request Quote、Contact、Privacy、Terms；
- 业务范围以 owner 确认后的 offering 和内容配置为准。
- 产品或服务详情页由派生站按真实业务增加，并复用同一询盘链路。

## 非目标

这不是通用 starter、博客系统或多站点 profile 平台。旧 starter 资料、旧 locale 路由、旧产品命名和历史计划不能覆盖当前运行事实。

## 主要用户旅程

了解业务范围 -> 查看公司与合作说明 -> 提交联系或报价询盘 -> 由真实服务和 owner 处理后续。

当前业务事实以代码和内容入口为准：offering 配置、MDX 页面、消息包和站点配置优先于旧文档。

## 内容与品牌入口

- 品牌事实：src/config/single-site.ts；
- SEO 与 crawl：src/config/single-site-seo.ts；
- 页面正文：content/pages/en/*.mdx；
- UI 文案：messages/base/**、messages/profiles/b2b-lead/**；
- 业务事实：offering 配置和内容入口。

不要把长正文塞进 messages，也不要在页面组件里硬编码用户可见文案。title / description 是页面内容输入，seo.title / seo.description 是 metadata 输入；updatedAt 表示买家可见内容变更，lastReviewed 表示人工复核时间。

文案必须准确表达业务范围、交付和询盘承诺。旧 starter 文案、占位 profile、未经 owner 确认的供应商或性能声明不能进入公开内容。新增语言必须同步 locale 配置、messages、MDX、SEO 和路由测试，不能只复制页面文件。
