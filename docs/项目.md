# 项目

Tucsenberg 是面向 OEM / 批发客户的英文 B2B 防洪挡板官网。

## 当前目标

- 展示产品并帮助买家比较规格；
- 提供 PDF 下载和报价准备；
- 承接 Request Quote / Contact 询盘；
- 在 Cloudflare 上稳定部署 OpenNext 站点。

## 当前公开范围

- 只有英文公开站点；
- 公开路径不带 locale 前缀；
- 产品线：ABS flood barriers、Aluminum flood gates、Absorbent flood bags、Flood tube dams、FRP flood barriers；
- PDF 下载必须保持 noindex。

## 非目标

这不是通用 starter、博客系统或多站点 profile 平台。旧 starter 资料、旧 locale 路由、旧产品命名和历史计划不能覆盖当前运行事实。

## 主要用户旅程

产品发现 -> 查看产品详情和规格 -> 下载资料 -> 提交 OEM / 批发询盘 -> 由真实服务和 owner 处理后续。

当前产品事实以代码和内容入口为准：产品配置、MDX 页面、消息包和站点配置优先于旧文档。

## 内容与品牌入口

- 品牌事实：src/config/single-site.ts；
- 页面表达：src/config/single-site-page-expression.ts；
- SEO 与 crawl：src/config/single-site-seo.ts；
- 页面正文：content/pages/en/*.mdx；
- UI 文案：messages/base/**、messages/profiles/b2b-lead/**、messages/profiles/catalog/**；
- 产品事实：src/constants/tucsenberg-product-page-*.ts 和 assembled product pages。

不要把长正文塞进 messages，也不要在页面组件里硬编码用户可见文案。title / description 是页面内容输入，seo.title / seo.description 是 metadata 输入；updatedAt 表示买家可见内容变更，lastReviewed 表示人工复核时间。

文案必须准确表达产品、规格、交付和询盘承诺。旧 starter 文案、占位 profile、未经 owner 确认的供应商或性能声明不能进入公开内容。新增语言必须同步 locale 配置、messages、MDX、SEO 和路由测试，不能只复制页面文件。
