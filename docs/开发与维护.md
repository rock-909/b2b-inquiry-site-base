# 开发与维护

## 常用入口

- 安装依赖：pnpm install；
- 全面本地检查：pnpm website:check；
- 内容检查：pnpm content:check；
- 普通构建：pnpm build；
- Cloudflare 构建：pnpm website:build:cf；
- 发布证明：pnpm release:verify；
- 外部 URL smoke：workflow_dispatch preview 分支只检查传入 URL 表面健康；
- 部署后 smoke：按正式上线标准使用真实部署地址。

build 与 Cloudflare build 必须串行。

## CI 与门禁作用

| 能力 | 保护什么 | 失败意味着什么 | 不能证明什么 |
| --- | --- | --- | --- |
| format / lint / type-check | 代码可解析、风格和类型边界 | 当前变更不能进入正常工程流程 | 不证明业务行为或线上运行 |
| Vitest 单元/集成 | 共享函数、API 契约和安全行为 | 已覆盖行为出现回归 | 不覆盖全部浏览器和真实 provider |
| Playwright | 浏览器用户旅程、无 JS 和 smoke | 指定运行环境的用户流程失败 | 预览不等于生产，不证明 owner receipt |
| content/i18n checks | message 包结构、locale parity、内容契约 | 内容或翻译输入不满足约定 | 不证明文案业务正确 |
| component governance | UI 入口、复用和设计规则 | 组件治理契约失真 | 不证明视觉审美或全站截图 |
| dependency/architecture checks | import 边界、依赖和结构约束 | 结构越界或死依赖风险 | 不证明运行时所有路径 |
| Cloudflare/OpenNext checks | 生成物、header 语义和平台配置 | 发布包或平台语义无法证明 | 不证明真实 Cloudflare 账号已部署 |
| external URL smoke | 手动传入的公开 URL 表面是否可访问 | 这个 URL 当前不可用或路由异常 | 不证明当前 SHA、构建产物或部署归属 |
| release:verify | 当前 checkout 的综合 release proof | 不能称为 release-proven | 不等于 public launch approval |
| strict production config | 正式环境关键配置边界 | 生产配置不满足上线前提 | 不证明 provider 已收到真实询盘 |
| deployed smoke | 公开部署的页面和关键 GET | 部署表面不可用 | 不证明 Airtable/Resend/Turnstile receipt |
| Airtable write canary | 真实部署的 Turnstile 提交和 Airtable 写入 | 公开上线仍不能通过 | 不证明 Resend 送达或 owner 收件 |
| owner receipt | owner inbox 实际收到通知 | 公开上线仍不能通过 | 不能由 Airtable 记录或本地绿灯代替 |

CI green 只是工程证据。外部 required check、GitHub ruleset、Cloudflare environment protection 和真实服务 receipt 需要独立证明。

## 维护边界

只改真实入口，不复制生成文件。生成的 src/lib/content-manifest.generated.ts 用 starter-checks 重新生成。AI 协作规则只保留项目独有事实，通用 skill 由全局插件承担。

## 环境变量

完整键位以 .env.example 为准。部署和验证常用键包括：AIRTABLE_API_KEY、AIRTABLE_BASE_ID、AIRTABLE_TABLE_NAME、RESEND_API_KEY、EMAIL_FROM、EMAIL_REPLY_TO、TURNSTILE_SECRET_KEY、TURNSTILE_ALLOWED_HOSTS、TURNSTILE_BYPASS、NEXT_PUBLIC_TURNSTILE_SITE_KEY、CLOUDFLARE_ACCOUNT_ID、CLOUDFLARE_API_TOKEN、DEPLOYMENT_PLATFORM、CLOUDFLARE_PREVIEW_BASE_URL、DEPLOY_SMOKE_BASE_URL、DEPLOY_SMOKE_HEADER_NAME、DEPLOY_SMOKE_HEADER_VALUE、PLAYWRIGHT_BASE_URL、PLAYWRIGHT_PROFILE_LANE、PLAYWRIGHT_REBUILD_SERVER、POST_DEPLOY_TEST、STAGING_URL、CI_DAILY、CI_FLAKE_SAMPLING、RATE_LIMIT_PEPPER、UPSTASH_REDIS_REST_URL、UPSTASH_REDIS_REST_TOKEN、ALLOW_MEMORY_RATE_LIMIT、CSP_REPORT_URI、CORS_ALLOWED_ORIGINS、GOOGLE_SITE_VERIFICATION、YANDEX_VERIFICATION、SECURITY_HEADERS_ENABLED、SKIP_ENV_VALIDATION。

`ALLOW_MEMORY_RATE_LIMIT=true` 是 release/proof blocker，不是本地 fallback 的普通开关。

## 故障处理

先确认运行态，再查配置、脚本和文档。遇到并行构建、固定端口、外部凭据或真实服务缺失时，记录证据边界，不把未执行写成通过。
